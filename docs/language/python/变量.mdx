## [变量](https://realpython.com/python-variables/)

### 认识 Python 中的变量

在 Python 中，变量是与计算机内存中存储的具体对象或值相关联的名称。通过将变量与值关联，你可以使用具有描述性的名称来引用该值，并在代码中根据需要多次复用它。

变量的行为就像它们所引用的值一样。要在代码中使用变量，首先需要学习如何创建它们，这在 Python 中非常直观明了。

### 通过赋值创建变量

在 Python 中创建变量的主要方式是使用赋值运算符（assignment operator），其语法如下：

```python
variable_name = value
```

在该语法中，左侧是变量名，接着是赋值运算符（`=`），右侧则是要赋给该变量的值。此处的赋值对象可以是任何 Python 对象，包括[字符串](https://realpython.com/python-strings/)、[数字](https://realpython.com/python-numbers/)、[列表](https://realpython.com/python-list/)、[字典](https://realpython.com/python-dicts/)，甚至是自定义对象。

## Python 中的变量命名

前面的示例使用的是简短的变量名。在实际开发中，变量名应当具有描述性以提高代码的可读性，因此变量名往往较长且包含多个单词。

在以下部分中，你将学习在 Python 中创建有效变量名所要遵循的规则，以及变量命名的最佳实践。

### 变量命名规则

Python 中的变量名可以是任意长度，可以由大写字母（A-Z）、小写字母（a-z）、数字（0-9）和下划线（`_`）组成。唯一的限制是：**虽然变量名可以包含数字，但变量名的第一个字符不能是数字**。

:::note[提示]

Python 目前具备完整的 [Unicode](https://realpython.com/python-encodings-guide/) 支持，变量名中可以使用许多 Unicode 字符。例如，以下变量名都是有效的：

```python
>>> α = 45
>>> β = 90
>>> δ = 180
>>> π = 3.14
```

这些变量名在常规 Python 代码中可能不常见，但完全合法。在执行科学计算时，如果你希望代码贴合对应学科的符号表示，可以使用它们。

:::


以下都是合法的变量名：

```python
>>> name = "Bob"
>>> year_of_birth = 1970
>>> is_adult = True
```

这些变量符合在 Python 中创建有效变量名的规则，同时也遵循了最佳命名实践。

而下面的变量名不符合规则：

```python
>>> 1099_filed = False
  File "<input>", line 1
    1099_filed = False
    ^
SyntaxError: invalid decimal literal
```

此例中的变量名以数字开头，这在 Python 中是不允许的，因此会引发 [SyntaxError](https://realpython.com/invalid-syntax-python/) 异常。

另外需要特别注意：**变量名大小写敏感**。小写字母和大写字母被视为不同的字符：

```python
>>> age = 1
>>> Age = 2
>>> aGe = 3
>>> AGE = 4
>>> age
1
>>> Age
2
>>> aGe
3
>>> AGE
4
```

在此示例中，Python 将这些名称解释为完全不同且相互独立的变量。因此在 Python 中命名变量时必须考虑大小写。

虽然语法上并不阻止你在同一个程序中创建名为 `age`、`Age` 或 `agE` 的多个变量，但极不推荐这种做法，因为它会让阅读代码的人（甚至是过了一段时间后的你自己）感到困惑。通常情况下，创建变量名时应一律使用小写字母。

下划线字符的作用也十分关键。你可以使用下划线来分隔变量名中的多个单词：

```python
>>> first_name = "John"
>>> pen_color = "red"
>>> next_node = 123
```

在这些变量名中，下划线用作多单词之间的分隔符，通过替代空格来提高代码的可读性。对比一下如果没有下划线的效果：

```python
>>> firstname = "John"
>>> pencolor = "red"
>>> nextnode = 123
```

尽管这些名称在技术上合法，但一眼看上去很难阅读和理解。缺少分隔让快速理解每个变量的含义变得更加困难。使用下划线能显著提高代码的清晰度与可维护性。

### 变量命名最佳实践

应当始终给变量赋予具有描述性、能清晰解释其用途的名称。有时可以用单个单词来命名变量：

```python
>>> temperature = 25
>>> weight = 54.5
>>> message = "Hello, Pythonista!"
```

变量始终引用具体的对象，因此其名称通常应为**名词**。应当为变量寻找具体的名字以唯一标识所引用的对象。类似 `variable`、`data` 或 `value` 这样的名字过于宽泛，虽然在简短的示例中可用，但在生产代码中缺乏足够的描述性。

通常应避免使用单字母名称：

```python
>>> t = 25  # 不推荐
>>> temperature = 25  # 推荐
```

单字母名称难以辨析，尤其是在与其他类似名称一起出现在复杂表达式中时，会导致代码可读性变差。当然也有例外，例如在处理嵌套列表或矩阵时，可以使用单字母名称表示索引：

```python
>>> matrix = [
...     [9, 3, 8],
...     [4, 5, 2],
...     [6, 4, 3],
... ]
>>> for i in matrix:
...     for j in i:
...         print(j)
...
9
3
8
4
5
2
6
4
3
```

通常使用 `i`、`j`、`k` 表示索引，在合适的上下文中这样使用是完全可接受的；同样，使用 `x`、`y`、`z` 表示坐标点也是常见做法。

不鼓励使用缩写来命名变量，提倡使用完整名称：

```python
>>> doc = "Freud"  # 不推荐
>>> doctor = "Freud"  # 推荐
```

使用完整名称更为清晰易读。不过，在一些已被广泛接受和通用的缩写场景下也是可以的：

```python
>>> cmd = "python -m pip list"
>>> msg = "Hello, Pythonista!"
```

在这些示例中，`cmd` 是 `command` 的公认缩写，`msg` 是 `message` 的公认缩写。Python 中广泛使用的缩写经典例子还有 `cls`，用于在[类方法（class method）](https://realpython.com/ref/glossary/class-method/)中表示当前类对象。

有时需要多个单词才能组成一个具有描述性的变量名。如果多单词之间没有明显界限，阅读起来会非常费力：

```python
>>> numberofgraduates = 200
```

这种变量名难以阅读，必须仔细辨认单词边界才能理解其含义。

多单词变量名最常见的命名风格有以下几种：

- **[蛇形命名法（Snake case）](https://realpython.com/ref/glossary/snake-case/)**：小写单词之间用下划线分隔。例如：`number_of_graduates`。
- **[驼峰命名法（Camel case）](https://realpython.com/ref/glossary/camel-case/)**：第二个及后续单词首字母大写。例如：`numberOfGraduates`。
- **[帕斯卡命名法（Pascal case）](https://realpython.com/ref/computer-science-glossary/pascal-case/)**：与驼峰命名类似，但第一个单词的首字母也大写。例如：`NumberOfGraduates`。

Python 代码风格指南（PEP 8）包含了各类对象名称的命名约定建议。对于变量，**PEP 8 推荐使用蛇形命名法（snake_case）**。

当需要多单词名称时，通常将形容词修饰语与名词结合使用：

```python
>>> initial_temperature = 25
>>> current_file = "marketing_personnel.csv"
>>> next_point = (2, 4)
```

通过组合形容词和名词，可以极大地提升代码可读性。另外要避免以 `my_` 开头的多单词名称（如 `my_file`、`my_color` 等），因为 `my_` 前缀并不能为命名提供任何有用的信息。

布尔标志变量也是多单词命名的典型用例：

```python
>>> is_authenticated = True
>>> has_permission = False
```

对于列表和字典，多数情况下应使用复数名词：

```python
>>> fruits = ["apple", "banana", "cherry"]
>>> colors = {
...     "Red": (255, 0, 0),
...     "Green": (0, 255, 0),
...     "Blue": (0, 0, 255),
...     "Yellow": (255, 255, 0),
...     "Black": (0, 0, 0),
...     "White": (255, 255, 255),
... }
```

使用复数名词清晰地传达了该变量是一个存储多个同类对象的容器。

在命名元组时，考虑到它们通常用于存储不同类型或含义的对象，因此可以使用单数名词：

```python
>>> color = (255, 0, 0)
>>> row = ("Jane", 25, "Python Dev", "Canada")
```

虽然这些元组存储了多个对象，但它们表示一个单一实体。第一个元组表示一种 RGB 颜色，第二个则表示数据库表中的一行记录。

### 公开与非公开变量名

Python 中广泛使用的变量命名约定是：当你需要表明某个变量是 Python 中所谓的非公开（non-public）变量时，在变量名前加上**单下划线前缀**。非公开变量是不应在其所属模块之外使用的变量，仅供内部（internal）使用：

```python
# timeout.py

_timeout = 30

def get_timeout():
    return _timeout

def set_timeout(seconds):
    global _timeout
    _timeout = seconds
```

在该模块中，有一个名为 `_timeout` 的非公开变量，以及两个操作该变量的函数。该变量本身并不打算在包含模块的外部直接使用。

### 受限与不推荐使用的名称

Python 保留了一小组被称为关键字（keywords）的词汇，它们是语言语法的一部分。可以通过以下代码获取 Python 的关键字列表：

```python
>>> import keyword
>>> keyword.kwlist
['False', 'None', 'True', 'and', 'as', 'assert', 'async', ..., 'yield']
```

大多数情况下，如果直接将这些词用作变量名，会导致语法错误：

```python
>>> class = "Business"
  File "<input>", line 1
    class = "Business"
          ^
SyntaxError: invalid syntax
```

如果确实需要使用与关键字重名的名称，可以遵循 PEP 8 的建议：**在名称末尾添加单下划线**：

```python
>>> class_ = "Business"
```

虽然这种约定可行，但有时更优雅的做法是换用更具体的名称：

```python
>>> passenger_class = "Business"
```

此时变量名更加具体且具描述性，可读性更佳。

此外还有软关键字（soft keywords），它们仅在特定语境下被视作关键字。例如 `match` 关键字仅在结构化模式匹配中才是关键字。因为 `match` 是软关键字，所以你仍可以将其用作变量名：

```python
>>> import re
>>> text = "Some text containing a number: 123"
>>> match = re.search("123", text)
>>> if match:
...     print("Found a match 😃")
... else:
...     print("No match found 😔")
...
Found a match 😃
```

另一个应避免的做法是使用内置名称（built-in names）来命名变量。例如，学习列表时写了如下代码：

```python
>>> list = [1, 2, 3, 4]
>>> list
[1, 2, 3, 4]
```

这会导致原始的内置 `list` 类型被遮蔽（shadowing），后续调用内置函数时将发生错误：

```python
>>> list(range(10))
Traceback (most recent call last):
  ...
TypeError: 'list' object is not callable
```

因此切忌使用内置名称作为变量名。

:::note[提示]

在交互式会话中运行以下代码可查看内置名称的完整列表：

```python
>>> import builtins
>>> dir(builtins)
['ArithmeticError', 'AssertionError', 'AttributeError', ..., 'tuple', 'type', 'vars', 'zip']
```

要检查变量名是否遮蔽了内置名称，可以使用 `"name" in dir(builtins)`。如果返回 `True`，建议换用其他名称。此规则对于第三方库中定义的对象名称同样适用。

:::

## 探索变量的核心特性

深入探究 Python 变量的底层工作原理时，会发现几个有趣的特性：

### 变量持有对象的引用

使用赋值语句创建变量时底层到底发生了什么？在 Python 中，这个问题的答案与许多其他编程语言不同。

Python 是一门面向对象编程语言。Python 程序中的每块数据都是特定类型或类的对象。看下面的代码：

```python
>>> 300
300
```

当执行 `300` 语句时，Python 完成了以下操作：

1. 创建一个整型对象；
2. 赋予其值 300；
3. 将其显示在屏幕上。

使用内置的 [type()](https://realpython.com/python-built-in-functions/#creating-and-checking-types-type-isinstance-and-issubclass) 函数可以确认该整型对象的创建：

```python
>>> type(300)
<class 'int'>
```

Python 变量是一个**符号名称**，它**引用**或指向像 300 这样的对象。一旦将对象赋值给变量，就可以通过变量名来引用它，但数据本身始终包含在对象内部。

例如，考虑以下变量定义：

```python
>>> n = 300
```

该赋值语句创建了一个值为 300 的整型对象，并使变量 `n` 指向该对象。

在 Python 中，**变量并不存储对象本身，而是指向或引用对象**。每次在 Python 中创建对象时，该对象都会被分配一个唯一的标识编号，然后该编号与变量相关联。

内置的 [id()](https://realpython.com/python-built-in-functions/#knowing-an-objects-identity-id) 函数返回对象的唯一标识符（identity）：

```python
>>> n = 300
>>> id(n)
4399012816
```

在标准 Python 实现 CPython 中，对象的 identity 即为其内存地址。因此，CPython 变量中实际存储的是内存地址，通过该内存地址来访问内存中的具体对象。

你可以创建多个指向同一对象的变量（即持有相同内存地址的变量）：

```python
>>> m = n
>>> id(n) == id(m)
True
```

在此示例中，Python 没有创建新对象，而是创建了一个新的变量名（引用）`m`，指向 `n` 所指向的同一对象。

接着假设执行：

```python
>>> m = 400
```

此时 Python 会创建一个值为 400 的新整型对象，并将 `m` 改为指向它。

最后执行：

```python
>>> n = "foo"
```

Python 创建了一个值为 `"foo"` 的字符串对象，并让 `n` 引用该对象。

经过对 `n` 和 `m` 的重新赋值，原先的整型对象 300 不再有任何引用，变成了“孤儿对象”（orphaned object），你将无法再次访问它。

当一个对象的引用计数降为 0 时，该对象将无法再被访问，生命周期随之结束。Python 会回收分配的内存以便再利用。在编程术语中，此过程被称为垃圾回收（Garbage Collection）。

### 变量具有动态类型

在许多静态类型语言中，变量在整个生命周期中被声明为具有固定的特定数据类型，赋予该变量的值必须属于该类型。

而 Python 变量并非如此。在 Python 中，你可以在不同时刻将不同数据类型的值赋给同一个变量：

```python
>>> value = "A string value"
>>> value
'A string value'
>>> # 之后重新赋值
>>> value = 23.5
>>> value
23.5
```

变量数据类型的变更可能引发运行时错误。例如，如果变量类型发生意外改变，可能导致类型相关的 Bug 甚至抛出异常：

```python
>>> value = "A string value"
>>> value.upper()
'A STRING VALUE'
>>> # 之后
>>> value = 23.5
>>> # 再次尝试使用 .upper()
>>> value.upper()
Traceback (most recent call last):
  ...
AttributeError: 'float' object has no attribute 'upper'
```

### 变量可以使用类型提示

你可以使用类型提示（Type Hints）为变量添加显式的类型信息。语法如下：

```python
variable: data_type [= value]
```

方括号表示该部分是可选的。在 Python 中，确实可以声明一个变量而不为其赋值：

```python
>>> number: int
>>> number
Traceback (most recent call last):
  ...
NameError: name 'number' is not defined
```

第一行的变量声明是合法的 Python 语法，但并没有真正创建变量实体，因此访问时会引发 NameError。尽管如此，Python 已经在内部记录了该类型提示。

对于数字、字符串等基础数据类型，类型提示有时略显多余：

```python
>>> language: str = "Python"
>>> number: int = 42
>>> coefficient: float = 2.87
```

但对于列表、元组、字典和集合等容器类型，为其包含的数据提供类型提示就很有价值了。例如：

```python
>>> colors: dict[str, str] = {
...     "red": "#FF0000",
...     "green": "#00FF00",
...     "blue": "#0000FF",
...     "yellow": "#FFFF00",
...     "black": "#000000",
...     "white": "#FFFFFF",
... }
```

或者使用 RGB 元组的字典：

```python
>>> colors: dict[str, tuple[int, int, int]] = {
...     "Red": (255, 0, 0),
...     "Green": (0, 255, 0),
...     "Blue": (0, 0, 255),
...     "Yellow": (255, 255, 0),
...     "Black": (0, 0, 0),
...     "White": (255, 255, 255),
... }
```

在用空容器初始化变量时，类型提示尤其实用：

```python
>>> fruits: list[str] = []
>>> rows: list[tuple[str, int, str]] = []
```

这样即使容器为空，静态类型检查器（Linter）与读者也能明确容器内预期存放的对象类型。后续可以使用相关方法追加数据：

```python
>>> fruits.append("apple")
>>> fruits.append("orange")
>>> rows.append(("Jane", 25, "Python Dev"))
>>> rows.append(("John", 30, "Web Dev"))
```

## 创建变量的补充方式

除了最基本的赋值外，Python 还提供了多种创建变量的方式：

### 并行赋值

Python 允许在单行代码中执行多次赋值，从而可以同时将相同的值赋给多个变量：

```python
>>> is_authenticated = is_active = is_admin = False
>>> is_authenticated
False
>>> is_active
False
>>> is_admin
False
```

相比逐行单独赋值，并行赋值更加简洁紧凑。

### 可迭代对象解包

可迭代对象解包（Iterable Unpacking，也称元组解包）是 Python 的一大特色功能，它将可迭代对象中的各个值分配给一系列变量：

```python
>>> person = ("Jane", 25, "Python Dev")
>>> name, age, job = person
>>> name
'Jane'
>>> age
25
>>> job
'Python Dev'
```

解包的一个绝佳用例是在无需临时变量的情况下交换两个变量的值：

```python
>>> a = 5
>>> b = 10
>>> a, b = b, a
>>> a
10
>>> b
5
```

在此示例中，等号右侧是一个元组 `(b, a)`，通过解包直接完成了值交换。

### 赋值表达式（海象运算符）

赋值表达式允许在条件语句或 `while` 循环中一步完成“求值并赋值”。例如传统的循环输入：

```python
>>> line = input("Type some text: ")
>>> while line != "stop":
...     print(line)
...     line = input("Type some text: ")
...
```

使用赋值表达式（海象运算符 `:=`）可以将其重写为：

```python
>>> while (line := input("Type some text: ")) != "stop":
...     print(line)
...
Type some text: Python
Python
Type some text: Walrus
Walrus
Type some text: stop
```

在 `(line := input("Type some text: "))` 中，创建了新变量 `line` 并将输入数据赋给它，同时将该表达式的值与 `"stop"` 进行比较，避免了重复调用 `input()`。

:::note[提示]

想要了解关于赋值表达式的更多详情，请参阅教程 [海象运算符：Python 的赋值表达式](https://realpython.com/python-walrus-operator/)。

:::

### 模式匹配

结构化模式匹配（Structural pattern matching） 也能通过捕获模式来创建变量。当 `case` 子句匹配成功时，Python 会将捕获到的值绑定到新变量：

```python
>>> command = ("move", 10, 25)
>>> match command:
...     case ("move", x, y):
...         print(f"Moving to ({x}, {y})")
...
Moving to (10, 25)
```

在此示例中，`x` 和 `y` 在 `match` 语句之前并不存在，`case` 模式通过提取匹配元组的第 2 和第 3 个元素创建了它们。

## 理解变量作用域

作用域（Scope）决定了变量和名称在代码中的可见性与查找方式。变量的作用域取决于创建该变量的位置。

Python 中最多存在 4 种不同的作用域，通常用 **LEGB** 规则表示：

- **L**ocal（局部作用域）
- **E**nclosing（闭包/外层嵌套函数作用域）
- **G**lobal（全局作用域）
- **B**uilt-in（内置作用域）

:::note[提示]

想要深入了解 Python 作用域机制，请参阅：

### 全局、局部与非局部变量

- **全局变量（Global variables）**：在模块级别创建的变量。在包含该变量的模块内部以及导入该模块的其他模块中均可见。在交互式 REPL 中，当前全局作用域定义在 `__main__` 模块中。
- **局部变量（Local variables）**：在函数内部定义的变量，仅在其所属函数内可见。函数执行完毕返回后，局部变量即销毁。
- **非局部变量（Non-local variables）**：在包含内部嵌套函数的外层函数中创建的变量。对于外层函数它是局部变量，但对于内部函数它属于非局部（non-local）变量，常用于闭包（closure）和装饰器（decorator）。

看下面的示例：

```python
# scopes.py

# 全局作用域
global_variable = "global"

def outer_func():
    # 闭包/非局部作用域
    nonlocal_variable = "nonlocal"

    def inner_func():
        # 局部作用域
        local_variable = "local"
        print(f"Hi from the '{local_variable}' scope!")
        print(f"Hi from the '{nonlocal_variable}' scope!")
        print(f"Hi from the '{global_variable}' scope!")

    inner_func()
```

调用 `outer_func()`：

```python
>>> from scopes import outer_func
>>> outer_func()
Hi from the 'local' scope!
Hi from the 'nonlocal' scope!
Hi from the 'global' scope!
```

:::note[提示]

内部函数可以直接**访问**全局变量和非局部变量。但若要在内部函数中**修改**它们，必须显式使用 [`global`](https://realpython.com/python-scope-legb-rule/#the-global-statement) 或 [`nonlocal`](https://realpython.com/python-scope-legb-rule/#the-nonlocal-statement) 语句声明。

:::

### 类变量与实例变量（属性）

在面向对象编程中，在类中创建的变量称为属性（attributes）。分为类属性和实例属性：

- **类属性**：在类定义级别创建的变量，由该类及其所有实例共享。
- **实例属性**：绑定到特定对象实例上的变量，每个实例独立拥有。

```python
# employees.py

class Employee:
    count = 0  # 类属性

    def __init__(self, name, position, salary):
        self.name = name          # 实例属性
        self.position = position  # 实例属性
        self.salary = salary      # 实例属性
        Employee.count += 1

    def display_profile(self):
        print(f"Name: {self.name}")
        print(f"Position: {self.position}")
        print(f"Salary: ${self.salary}")
```

使用示例：

```python
>>> from employees import Employee
>>> jane = Employee("Jane Doe", "Software Engineer", 90000)
>>> john = Employee("John Doe", "Product Manager", 120000)
>>> jane.display_profile()
Name: Jane Doe
Position: Software Engineer
Salary: $90000
>>> john.display_profile()
Name: John Doe
Position: Product Manager
Salary: $120000
>>> f"Total employees: {Employee.count}"
'Total employees: 2'
```

:::note[提示]

不能通过 `self` 来直接修改类属性的值。例如执行 `self.count += 1` 会在当前实例上创建一个遮蔽类属性的同名实例属性，而不会更改 `Employee.count`。要修改类属性，必须通过类名操作（如 `Employee.count = 100`）或 `type(self).count`。

:::

### 从作用域中删除变量

在 Python 中，可以使用 `del` 语句显式地从给定作用域中删除变量：

```python
>>> city = "New York"
>>> city
'New York'
>>> del city
>>> city
Traceback (most recent call last):
  ...
NameError: name 'city' is not defined
```

需要注意的是，`del` 删除的是对对象的**引用**，并不一定会立即释放内存。只有当对象的全部引用都归零时，Python 垃圾回收器才会回收该内存。

---

全局变量是指可以在代码的任何地方访问和修改的变量。在 Python 中，通常在模块级别定义全局变量。因此，包含它们的模块就是它们的作用域。

:::note
您也可以在函数内部定义全局变量，正如您将在“在函数内部创建全局变量”一节中了解到的那样。
:::

一旦定义了全局变量，您就可以在模块本身或代码中的其他模块内使用它。您也可以在函数中使用全局变量。然而，由于在函数中访问和修改全局变量之间存在差异，这些情况可能会变得有些令人困惑。

为了理解这些差异，请考虑 Python 可以在四种不同的作用域中查找变量：
* 存在于函数内部的局部（或函数级别）作用域。
* 存在于嵌套函数中的闭包（或非局部）作用域。
* 存在于模块级别的全局作用域。
* Python 内置名称的特殊作用域，即内置作用域。

举例来说，假设您位于一个内部函数中。在这种情况下，Python 可以在所有四个作用域中查找名称。

当您在该内部函数中访问一个变量时，Python 首先在该函数内部进行查找。如果该变量在那里不存在，那么 Python 将继续在外部函数的闭包作用域中查找。如果那里也没有定义该变量，那么 Python 将按顺序移动到全局作用域和内置作用域。如果 Python 找到了该变量，那么您将获得该返回值。否则，您将收到一个 `NameError`：

```python
>>> # Global scope
>>> def outer_func():
...     # Non-local scope
...     def inner_func():
...         # Local scope
...         print(some_variable)
...     inner_func()
...
>>> outer_func()
Traceback (most recent call last):
    ...
NameError: name 'some_variable' is not defined
>>> some_variable = "Hello from global scope!"
>>> outer_func()
Hello from global scope!

```

当您启动交互式会话时，它从全局作用域的模块级别开始。在这个例子中，您有 `outer_func()`，它将 `inner_func()` 定义为一个嵌套函数。从这个嵌套函数的角度来看，它自己的代码块代表局部作用域，而在调用 `inner_func()` 之前的 `outer_func()` 代码块代表非局部作用域。

如果您在没有在当前任何作用域中定义 `some_variable` 的情况下调用 `outer_func()`，那么您会得到一个 `NameError` 异常，因为该名称未定义。

如果您在全局作用域中定义了 `some_variable`，然后调用 `outer_func()`，那么您会在屏幕上看到 `Hello!`。在内部，Python 已经搜索了局部、非局部和全局作用域来找到 `some_variable` 并打印其内容。请注意，您可以在这三个作用域的任何一个中定义此变量，Python 都会找到它。

这种搜索机制使得从函数内部使用全局变量成为可能。然而，在利用这一特性的同时，您可能会面临一些问题。例如，访问变量是可行的，但直接修改变量却行不通：

```python
>>> number = 42
>>> def access_number():
...     return number
...
>>> access_number()
42
>>> def modify_number():
...     number = 7
...
>>> modify_number()
>>> number
42

```

`access_number()` 函数运行良好。它寻找 `number` 并在全局作用域中找到了它。相比之下，`modify_number()` 并没有按预期工作。为什么这个函数没有更新您的全局变量 `number` 的值呢？问题在于变量的作用域。您不能在像局部作用域这样的低级作用域中直接修改像全局作用域这样的高级作用域中的变量。

在内部，Python 假定在函数内直接分配的任何名称都是该函数的局部变量。因此，局部名称 `number` 遮蔽了它的全局同名变量。

在这个意义上，全局变量表现为只读名称。您可以访问它们的值，但不能修改它们。

:::note
关于在函数内部修改全局变量的讨论围绕的是赋值操作，而不是对可变对象的原地修改。您将在“理解可变性如何影响全局变量”一节中了解可变性对全局变量的影响。
:::

当您尝试在函数内部修改全局变量时，遇到 `UnboundLocalError` 异常是另一个常见问题。考虑以下尝试使用一些全局变量的演示函数：

```python
>>> a = 10
>>> b = 20
>>> c = 30
>>> def print_globals():
...     print(a, b, c)
...     c = 100
...     print(c)
...

```

在 `print_globals()` 内部，您首先打印全局变量 `a`、`b` 和 `c`。然后您直接更新 `c` 的值。最后，您打印更新后的 `c` 版本。您可能会期待以下输出：

```python
>>> # Expected output
>>> print_globals()
10 20 30
100

```

然而，这个输出永远不会出现在您的屏幕上。相反，您会收到一个可能会让您惊讶的错误：

```python
>>> print_globals()
Traceback (most recent call last):
    ...
UnboundLocalError: cannot access local variable 'c'
    where it is not associated with a value

```

问题在于赋值 `c = 100` 创建了一个新的局部变量，它覆盖了原始的全局变量 `c`。因此，您遇到了名称冲突。异常来自于第一次调用 `print()`，因为在那时，局部版本的 `c` 还未被定义。因此，您得到了 `UnboundLocalError`。

在实践中，这个问题最常出现在对全局变量进行增强赋值操作时：

```python
>>> counter = 0
>>> def increment():
...     counter += 1
...
>>> increment()
Traceback (most recent call last):
    ...
UnboundLocalError: cannot access local variable 'counter'
    where it is not associated with a value

```

在 Python 中，如果您的函数只是从全局作用域引用一个变量，那么该函数假定该变量是全局的。如果您在函数体内的任何地方为该变量名赋值，那么您就定义了一个与原始全局变量同名的新局部变量。

在函数内部，如果您在函数的任何地方定义了同名的局部变量，则无法直接访问全局变量。

如果想在函数内部修改全局变量，则需要显式告诉 Python 使用全局变量，而不是创建一个新的局部变量。为此，您可以使用以下方法之一：

1. `global` 关键字。
2. 内置的 `globals()` 函数。

在接下来的部分中，您将学习如何在代码中使用这两种工具来从函数内部更改全局变量。

## `global` 关键字

您已经了解到，从函数内部直接访问全局变量是完全可能的，除非包含它的函数中有同名的局部变量。除此之外，如果您还需要更改变量的值怎么办？在这种情况下，您可以使用 `global` 关键字来声明您想要引用该全局变量。

编写 `global` 语句的一般语法如下：

```python
global variable_0, variable_1, ..., variable_n

```

请注意，第一个变量是必需的，而其余的变量是可选的。为了说明如何使用此语句，回到 `counter` 和 `increment()` 示例。您可以通过执行类似以下操作来修复代码：

```python
>>> counter = 0
>>> def increment():
...     global counter
...     counter += 1
...
>>> increment()
>>> counter
1
>>> increment()
>>> counter
2

```

在这个新版本的 `increment()` 中，您使用 `global` 关键字来声明希望函数更新全局变量 `counter`。通过此语句，您现在能够修改函数内部 `counter` 的值，正如您在上面看到的。

:::note
Python 有一个 `nonlocal` 关键字，其工作原理类似于 `global`。它允许您在嵌套函数中使用非局部变量。非局部变量是指您在包含嵌套函数的函数中定义的变量。这些变量对内部或嵌套函数来说将是非局部的。
:::

需要注意的是，您必须在使用目标变量之前进行全局声明。否则，您将收到一个 `SyntaxError`：

```python
>>> counter = 0
>>> def increment():
...     counter += 1
...     global counter
...
SyntaxError: name 'counter' is assigned to before global declaration

```

在这个例子中，您试图在没有在 `increment()` 内将其声明为 `global` 的情况下递增 `counter`。因此，您得到了一个 `SyntaxError`。

`global` 语句告诉 Python 解释器，当您在这个函数中找到名称 `counter` 时，它指的是全局变量，所以不要创建局部变量。

总之，只有在您想在函数内重新分配全局变量时，才需要使用 `global` 关键字。如果您只需要从函数内部读取或访问全局变量的值，则不需要 `global` 关键字。

尽管 `global` 关键字的目的是在函数中处理全局变量，但这个关键字并不是您可用于此目的的唯一工具。您也可以使用内置的 `globals()` 函数。

## `globals()` 函数

内置的 `globals()` 函数允许您访问全局作用域的名称表，这是一个可写字典，包含您当前的全局名称及其对应的值。您可以使用此函数从函数内部访问或修改全局变量的值。

例如，当您有与目标全局变量同名的局部变量，并且仍然需要在函数内部使用全局变量时，此函数非常有用：

```python
>>> a = 10
>>> b = 20
>>> c = 30
>>> def print_globals():
...     print(a, b, globals()["c"])
...     c = 100
...     print(c)
...
>>> print_globals()
10 20 30
100
>>> c
30

```

在这个 `print_globals()` 的新实现中，`c` 指的是变量的局部版本，而 `globals()["c"]` 指的是全局版本。

由于 `globals()` 返回一个字典，因此您可以像访问常规字典的键一样访问其键。请注意，您需要使用变量的名称作为字符串来访问 `globals()` 中的对应键。

`globals()` 返回的名称字典是可变的，这意味着您可以利用该字典更改现有全局变量的值。在最后一个示例中，您可以看到全局变量 `c` 仍然持有相同的值。

这是另一个版本的 `increment()`。它稍微有点难读，但它有效：

```python
>>> counter = 0
>>> def increment():
...     globals()["counter"] += 1
...
>>> increment()
>>> counter
1
>>> increment()
>>> counter
2

```

在这个例子中，您使用 `globals()` 而不是 `global` 关键字实现了 `increment()`。这两种实现的工作方式相同，您可以通过连续调用函数后 `counter` 的内容来确认这一点。

请注意，使用 `globals()` 来访问和更新全局变量可能会使您的代码难以阅读和理解，特别是对于大型程序。一般情况下，除非您有与目标全局变量同名的局部变量，否则最好使用 `global` 关键字。

## 理解可变性如何影响全局变量

Python 拥有可变和不可变的数据类型。可变类型（例如列表和字典）允许您就地更改或变异它们的值。相比之下，不可变类型（如数字、字符串和元组）不允许您就地修改它们的值。

为了快速说明可变性和不可变性在 Python 中是如何工作的，考虑以下示例，您就地变异一个列表，更改其元素或项目的值：

```python
>>> numbers = [1, 2, 3]
>>> id(numbers)
4390329600
>>> numbers[0] = 10
>>> numbers[1] = 20
>>> numbers[2] = 30
>>> numbers
[10, 20, 30]
>>> id(numbers)
4390329600

```

在这个例子中，您变异了 `numbers` 的值。由于 Python 列表是可变对象，这种变异不会改变您列表对象的标识，仅改变其值。在进行变异前后，您可以通过比较内置 `id()` 函数的输出来确认这一点。

现在，如果您尝试在诸如元组这样的不可变类型上执行类似操作会发生什么？在这个代码示例中，您尝试了一下：

```python
>>> letters = ("a", "b", "c", "d")
>>> letters[0] = "aa"
Traceback (most recent call last):
    ...
TypeError: 'tuple' object does not support item assignment

```

这里，您使用元组来存储字母。Python 元组是不可变的，因此您不能像对数字列表那样就地更改它们的项目。如果您尝试这样做，就会得到一个 `TypeError`。

当在函数内部使用指向可变对象的全局变量时，您会注意到可以直接就地更改它们的值。

例如，假设您正在创建一个 REST API 应用程序。为了方便起见，您使用一个全局字典跨应用代码共享 API 配置。同样为了方便，您编写了一个允许您更新配置参数的简短函数：

```python
>>> config = {
...     "base_url": "[https://example.com/api](https://example.com/api)",
...     "timeout": 3,
... }
>>> def update_config(**kwargs):
...     for key, value in kwargs.items():
...         if key in {"api_key", "base_url", "timeout"}:
...             config[key] = value
...         else:
...             raise KeyError(key)
...
>>> update_config(api_key="111222333")
>>> config
{
    'api_key': '111222333',
    'base_url': '[https://example.com/api](https://example.com/api)',
    'timeout': 3
}
>>> update_config(timeout=5)
>>> config
{
    'api_key': '111222333',
    'base_url': '[https://example.com/api](https://example.com/api)',
    'timeout': 5
}

```

在此示例中，`update_config()` 函数允许您更新应用程序的配置参数。该函数接受仅限关键字的参数。每个参数必须是具有相应值的有效配置参数。在条件语句中，您使用 `in` 运算符检查此条件。如果参数无效，那么函数会引发 `KeyError`。

因为 Python 字典是可变数据类型，所以无需使用 `global` 或 `globals()` 即可在 `update_config()` 内部就地更改 `config` 的值。如果它们是有效的配置参数，您甚至可以添加新的键值对。例如，对 `update_config()` 的第一次调用添加了 `api_key` 参数，而第二次调用更新了 `timeout` 参数。

需要注意的是，配置和设置通常是应用程序或系统全局状态的重要组成部分。在系统运行时更改配置会变异其全局状态。您应仅在非常小心的情况下进行此类更改。某些应用和软件系统在您更改其某些配置参数后要求重新启动或重新加载。这是处理这类状态变异的好方法。

## 在函数内部创建全局变量

正如您已经了解到的，您可以使用 `global` 关键字或内置的 `globals()` 函数在函数内部访问和修改全局变量。真正有趣且可能令人惊讶的是，您还可以使用这些工具在函数内部创建全局变量。

:::warning
虽然您可以使用 `global` 关键字或 `globals()` 函数在函数内部创建全局变量，但这是非常罕见的，而且不是最佳实践。它会使您的代码难以理解和维护。
:::

最好在任何函数外部的模块级别定义全局变量。这样，它们的作用域就很清楚了，而且如果您在调用定义函数之前使用该变量，就不会有遇到 `NameError` 的风险。

在这个例子中，您使用 `global` 关键字在函数内部创建了一个全局变量：

```python
>>> def set_global_variable():
...     global number
...     number = 7
...
>>> set_global_variable()
>>> number
7

```

在这里，`set_global_variable()` 函数使用 `global` 关键字将 `number` 定义为全局变量。当您调用函数时，`number` 被定义，并且它的值被设置为 7。在调用之后，您可以从程序中的任何其他位置访问 `number`。

您还可以使用 `globals()` 函数在函数内部定义新的全局变量。该工具为您提供了额外的灵活性，使您能够动态地创建全局变量：

```python
>>> def dynamic_global_variable(name, value):
...     globals()[name] = value
...
>>> dynamic_global_variable("number", 42)
>>> number
42

```

在此示例中，`dynamic_global_variable()` 函数使用 `globals()` 函数通过字符串名称和值定义新的全局变量。对函数的调用创建了一个名为 `number` 的新全局变量，其值为 42。

为了提供一个更现实的示例，假设您有一个 JSON 格式的配置文件。您想要处理该文件并将所有配置参数直接加载到您的全局命名空间中，以便您可以在代码的其他部分将这些参数用作全局变量。

您的 `config.json` 文件可能如下所示：

```json
{
    "database": {
      "host": "localhost",
      "port": 5432,
      "name": "database.db",
      "user": "username",
      "password": "secret"
    },
    "api_key": "111222333",
    "base_url": "[https://example.com/api](https://example.com/api)",
    "timeout": 60
}

```

该文件定义了一个 `"database"` 键，其值是一个包含键和值的字典。您将把此字典用作应用程序数据库的初始设置。该文件还定义了用于连接 API 的 API 密钥、基础 URL 和超时。

以下代码负责加载 JSON 文件并为您创建所需的一组全局变量：

```python
>>> import json
>>> def set_config_key(key, value):
...     globals()[key] = value
...
>>> with open("config.json") as json_config:
...     for key, value in json.load(json_config).items():
...         set_config_key(key, value)
...
>>> database
{

    'password': 'secret'
}
>>> api_key

```

在这个代码片段中，您定义了 `set_config_key()`，它以 `key` 和 `value` 作为参数。然后您使用 `globals()`，以 `key` 作为变量名，以 `value` 作为其值来创建一个全局变量。

在 `with` 语句中，您打开配置文件进行读取，并将文件对象分配给 `json_config` 变量。然后您使用一个 `for` 循环来处理加载的配置，并为每个键值对创建新的全局变量。

完成此过程后，您可以将代码中所有配置参数作为全局变量进行访问。

尽管在 Python 中使用 `global` 关键字或 `globals()` 函数在函数中定义全局变量是完全可能的，但这并不是最佳实践。以此方式定义全局变量时必须小心。这些变量将变得对整个程序可用，因此代码的其他部分可以修改它们。正因为如此，您最终可能会得到难以理解、测试、维护和调试的代码。

也许您注意到了某种模式。在函数中使用和定义全局变量的方法有很多，但这是否意味着您应该这么做？在下一部分中，您将探讨这个问题。

## 决定何时使用全局变量

在您的编程之旅中，您会发现某些情况下使用全局变量可能是合适的甚至是必要的。例如，您可能会使用全局变量来处理：

* 配置和设置：如果您有一些适用于整个程序的设置，那么使用全局变量可能是一个快速的解决方案，它将允许您从代码的任何地方访问这些设置。
* 小型实用脚本：如果您正在编写小型脚本来自动化部分工作流程或完成微小的任务，那么使用全局变量可以帮助您更快地运行，并阻止您过度设计解决方案。
* 缓存数据：如果您出于性能原因需要缓存数据，那么您可以利用全局变量来存储缓存的数据。

需要注意的是，您应该谨慎地并且仅在绝对必要时使用全局变量。如果决定在代码中使用全局变量，请务必记录其使用情况，特别要注意为什么依赖它们。

在实践中，在代码中使用全局变量可能会有一些缺点。例如，全局变量可能：

* 使跟踪变量的更改变得困难，因为您可以从代码的任何位置更改变量。
* 产生不必要的副作用，因为对全局变量的更改可能会影响代码其他部分的行为。
* 使代码难以测试和调试，因为函数的行为和结果将取决于全局变量的当前值。
* 影响代码的可重用性，因为依赖全局变量的函数与这些变量紧密耦合。
* 导致命名冲突，因为您可能会在代码的不同部分意外地重用全局名称，从而导致意外结果。
* 破坏封装性，因为全局变量在代码的不同部分之间引入了隐藏的依赖关系。
* 使代码难以重构，因为代码某一部分的更改可能会影响其他部分。

虽然您可以利用全局变量解决特定问题，但尽量减少在代码中的使用会更好。如果仍然需要使用它们，可以将它们作为常量，以避免它们的部分缺点。这是因为使用全局变量的大多数问题源于在代码执行期间更改它们的值。

在接下来的几节中，您将学习一些常用的策略和技术，以避免在函数中使用全局变量。

## 在代码和函数中避免使用全局变量

正如您在上一节中所了解的，在函数和代码中依赖全局变量可能会导致一些不良影响。这些变量可能会使代码更难理解、测试和调试。它们还可能导致难以维护和重用的代码。因此，您必须小心控制地使用全局变量。

幸运的是，您可以采用一些巧妙的策略来减少对全局变量的需求。

### 使用全局常量

也许避免全局变量最直观的策略就是使用全局常量。与变量不同，常量在代码执行期间不得更改其值。因此，它们促进了对全局名称的安全使用。

:::tip
Python 不支持严格常量或不可重新赋值的名称。要在 Python 中定义常量，应使用大写字母加下划线。然而，这只是命名约定，并不能阻止开发人员为您的常量分配新值。所以，您必须小心，千万不要编写更改常量值的代码。
:::

为了说明如何使用常量代替全局变量，假设您有一些常规配置参数，并希望可以从程序的所有部分访问它们。在这种情况下，可以使用全局常量。通常，在模块顶部导入之后定义常量。

下面是一些 Python 常量的示例：

```python
API_KEY = "111222333"
BASE_URL = "[https://example.com/api](https://example.com/api)"
TIMEOUT = 3

```

您可以使用常量存储在程序执行期间不会改变的值。常量可帮助防止意外修改值。它们还提高了代码的可读性和可维护性。

一旦定义了常量，即可在整个代码的函数中访问它们。您只需确保保持它们不变即可。例如，以下函数从 NASA 的主 API 页面加载图像：

```python title="nasa.py"
import webbrowser
import requests

API_KEY = "DEMO_KEY"
BASE_URL = "[https://api.nasa.gov/planetary](https://api.nasa.gov/planetary)"
TIMEOUT = 3

def load_earth_image(date):
    endpoint = f"{BASE_URL}/apod"
    try:
        response = requests.get(
            endpoint,
            params={
                "api_key": API_KEY,
                "date": date,
            },
            timeout=TIMEOUT,
        )
    except requests.exceptions.RequestException as e:
        print(f"Error connecting to API: {e}")
        return

    try:
        url = response.json()["url"]
    except KeyError:
        print(f"No image available on {date}")
        return

    webbrowser.open(url)

```

在此示例中，您从 Python 标准库中导入了 `webbrowser`。此模块可让您在其默认浏览器中快速打开 URL。然后导入 `requests` 库以向目标 REST API 发出 HTTP 请求。

在 `load_earth_image()` 中，您可以直接访问三个全局常量，就像处理 Python 中的任何全局变量一样。但是，您在函数内部不更改任何常量的值。

现在，您也可以在其他相关的函数中重复使用这些常量。以这种方式使用常量允许您改善代码的可读性和可维护性。此外，由于它们是常数，当您调试或测试代码时，您不必跟踪其当前值。您始终会知道它们的值。

要测试以上示例，请继续并运行以下代码：

```python
>>> from nasa import load_earth_image
>>> load_earth_image("2024-11-21")

```

对 `load_earth_image()` 的调用将为您获取 NASA 为 2024 年 11 月 21 日准备的图像。图像将在您的默认浏览器中打开。您可以尝试使用其他日期获取自己的图像。

### 在函数中接收参数并返回值

编写采用参数并返回值的函数，而不是依赖全局变量，这是在您的代码中避免使用全局变量的另一个好策略。这类函数被称为纯函数，并且是函数式编程的基础，该编程泛型目前十分流行。

纯函数通常与代码的其他部分完全分离。更重要的是，它们不会产生任何副作用，例如更改全局变量的状态。这些功能使它们更易于重用且更容易理解、调试、测试和维护。

例如，以下是不在函数内部使用全局变量的老朋友 `increment()` 的新实现。在此处，函数仅接受一个值作为参数，并将其增加 1 返回：

```python
>>> def increment(value=0):
...     return value + 1
...
>>> counter = increment()
>>> counter
1
>>> counter = increment(counter)
>>> counter
2
>>> counter = increment(counter)
>>> counter
3

```

`increment()` 的这个新版本不再依赖全局变量中的外部值。因此，其结果仅取决于它的输入参数。无论何时，只要参数相同，此函数总是返回相同的结果，这就使得这个函数更易于测试、理解和调试。

该函数与程序的任何其他部分完全解耦，以至于您甚至可以在不同的程序中重用它。

在这个例子中，您仅在全局作用域内改变 `counter` 变量。您不执行跨作用域突变，所以使代码更安全且更容易理解。

### 使用类、方法和属性

有时候您可能具有一个或多个作用在或伴随一些全局变量运行的函数。在这些情况下，您能考虑编写一个将函数转化为方法并将全局变量转化为实例属性的类。

例如，假设您正在编写一款应用程序来管理自己的银行账户。您通过创建一系列处理账户余额的函数来开始：

```python title="account_global.py"
balance = 0

def deposit(amount):
    global balance
    balance += amount
    print(f"Successful deposit: +${amount:,.2f}")

def withdraw(amount):
    global balance
    if balance - amount > 0:
        balance -= amount
        print(f"Successful withdrawal: -${amount:,.2f}")
    else:
        print("Not enough funds for this transaction")

def get_balance():
    return balance

def main():
    while True:
        operation = input(
            "What would you like to do?\n"
            " d) deposit  "
            " w) withdraw  "
            " b) balance  "
            " q) quit\n"
            "> "
        )
        if operation in "dD":
            amount = float(input("Enter the deposit amount: "))
            deposit(amount)
        elif operation in "wW":
            amount = float(input("Enter the withdrawal amount: "))
            withdraw(amount)
        elif operation in "bB":
            print(f"Current balance: ${get_balance():,.2f}")
        elif operation in "qQ":
            print("Goodbye!")
            break
        else:
            print("Invalid operation. Please try again.")

main()

```

在这段代码中，您依靠一个全局变量存储您的银行账户的余额。您具有三种提供共同操作账户余额功能的函数。您可以存钱、提款，并且检查您账户的现有余额。

`main()` 函数定义了一条向您显示文本用户界面 (TUI) 的 `while` 循环。通过此界面，您告诉该应用将想要进行的操作执行在自己的账户中。

太棒了！该应用程序按预期工作。它允许您存款、提取资金并检查您的当前余额。现在，假设您不喜欢过度依赖全局变量，并且您决定使用类来重构应用程序。为此，您需要执行以下步骤：

1. 用合适的名称定义一个类。`Account` 适用于此示例。
2. 将全局变量移入该类，将它们转换为实例属性。
3. 将函数作为实例方法移入该类。

这是重构的代码：

```python title="account_class.py"
class Account:
    def __init__(self, balance=0):
        self.balance = balance

    def deposit(self, amount):
        self.balance += amount
        print(f"Successful deposit: +${amount:,.2f}")

    def withdraw(self, amount):
        if self.balance - amount > 0:
            self.balance -= amount
            print(f"Successful withdrawal: -${amount:,.2f}")
        else:
            print("Not enough funds for this transaction")

def main():
    account = Account()
    while True:
        operation = input(
            "What would you like to do?\n"
            " d) deposit  "
            " w) withdraw  "
            " b) balance  "
            " q) quit\n"
            "> "
        )
        if operation in "dD":
            amount = float(input("Enter the deposit amount: "))
            account.deposit(amount)
        elif operation in "wW":
            amount = float(input("Enter the withdrawal amount: "))
            account.withdraw(amount)
        elif operation in "bB":
            print(f"Current balance: ${account.balance:,.2f}")
        elif operation in "qQ":
            print("Goodbye!")
            break
        else:
            print("Invalid operation. Please try again.")

main()

```

在会计程序的新版本中，您定义了一个名为 `Account` 的类。该类具有一个用于存储账户余额的实例属性。该属性曾是您的老全局变量 `balance`。

您还把 `deposit()` 和 `withdraw()` 方法转变成了包含当前实例 `self` 作为第一参数的实例方法。最后，在循环的内部，您实例化了 `Account` 类并在实例里使用该类调用它的方法从而使该程序运转时的情况犹如上代版本一样。

注意，在这个实现中，您没有 `.get_balance()` 方法。所以，要获得账户存款情况可以依靠其属性 `.balance` 实现。

```
